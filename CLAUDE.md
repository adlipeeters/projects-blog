# Repo rules

This repo holds the code for my blog projects. Each folder is a self-contained project with its
own spec, README, tooling and its own `CLAUDE.md` where the project needs more specific rules.

## Commits and pull requests

- Never add AI attribution to commit messages or pull request descriptions. No
  `Co-Authored-By` line for Claude or any other assistant, no "Generated with" footer, no
  attribution emoji. The commit author is me.
- Write the message for a reader skimming history: a short imperative subject line, then a body
  explaining why the change exists, not what the diff already shows.
- No ticket numbers or internal references. Readers of these projects come from the articles.

## Prose

Plain and direct, in commits, READMEs and docs. No em dashes, no hedging, no architecture-review
voice.
